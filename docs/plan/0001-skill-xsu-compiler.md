# XSU 编译器与三预设实施计划

> 状态：in-progress · 日期：2026-11-06 · Scope：skill
> 承接：[XSU 声明式内容与 HTML 渲染设计](../engineering/design/0003-skill-xsu-rendering.md)

## 目标与范围

用户已批准设计并授权开发。实现零运行时 npm 依赖的 XSU 解析、校验、编译和技能内独立分发；接入 editorial、replay-self、replay-public，保留现有视觉模板。接受设计建议的技能内分发生成物例外与 offline 默认、connected 显式启用的网络边界。不涉及发布远程、提交、推送或其他 HTML 技能迁移。

## 前置条件与风险

三个技能的模板与组件是视觉事实源；源码改动前保存 Git 现状，避免覆盖既有设计稿。报告组件与 Replay 适配分别开发，主会话管理共享契约、CLI、构建与发布文档。开发任务的完成必须复核文件和测试，不以代理摘要作为验收。远程 Pele 的联网需求、完整性与离线失败须明确呈现；浏览器环境不可用时不得声称视觉验收完成。

## 分阶段计划

- 核心接口：固定 AST `{type,args,loc}`、校验诊断、适配器输入输出；准出为 parser 与适配器能通过共同接口调用。
- 编译与 CLI：递归下降解析、Include 和资源沙箱、确定性模板装配、安全输出、validate/render/check/migrate 命令及分发构建；准出为核心与隔离安装测试通过。
- 三预设：报告现有组件和 SVG 数据渲染、Replay 领域校验与旧 JSON lowering、必要运行时补齐；准出为覆盖映射及领域回归通过，不静默舍弃不支持节点。
- 技能与发布：XSU 语法、组件参考、示例、版本、manifest、marketplace、README、INITDEEP 与 Cursor 导出同步；准出为构建检查和技能发现通过。
- 验收：全部 node 测试、生成物漂移、资源与攻击性输入边界、独立安装、实际浏览器主题/翻页/图表/导出检查；未通过项必须记录为剩余工作。

## 迁移与回滚

历史 HTML 不批量回写；旧 Replay 仅从合法 JSON 显式迁移。生成 HTML 不是编辑源。失败不覆盖旧输出，不退回 AI 手写 HTML。回退安装上一技能发布版本并保留 XSU 源文件；不重写 Git 历史。

## 验收与归档标准

- [x] 核心、组件、Replay 与安全回归通过。
- [x] 三份技能可独立安装和运行，build/check 无漂移。
- [x] 所有已登记组件变体有可核验的覆盖材料。
- [x] 三预设浏览器、主题、移动端和导出完成实际验收。
- [ ] 文档、版本、manifest 与根索引同步，仓库校验通过。
