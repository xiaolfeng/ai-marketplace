## 5. 📖 小词典（看不懂的词都在这）

| 词                              | 大白话                                                                                              |
| :------------------------------ | :-------------------------------------------------------------------------------------------------- |
| `Recreate`                      | K8s 换版本的一种方式：先把旧的全关掉，再开新的。只有一个副本时，中间就有一段「店门关着」的空窗      |
| `RollingUpdate`                 | 滚动更新：先把新店开起来接客，再关旧店，顾客不会吃闭门羹                                            |
| `ReadinessGate`                 | 新实例必须拿到「我真的准备好接单了」的通行证，负载均衡才会把流量切过去                              |
| `preStop`                       | 实例临死前先等几秒（这里是 10 秒），让外面的负载均衡来得及把它从名单里摘掉，别再往里塞新请求        |
| `502 空窗`                      | 负载均衡发现后面没有能接客的实例，只能给用户返回 502 错误的那段时间                                 |
| `1→2→1`                         | 同一个版本先从 1 个实例扩到 2 个，跑稳了再缩回 1 个，用来验证「两个实例同时跑会不会打架」           |
| `Argo` / `selfHeal`             | 按 Git 自动部署的工具；`selfHeal` 是它的自动纠正——你手动改过的东西，它几秒内就给改回 Git 里写的样子 |
| `overlay`                       | 每个环境（`dev-shared`、`canary`、`qa-bench`）贴在通用配置上面的那一层专属小补丁                    |
| `Checkout` / `OutboxDispatcher` | 这个项目里的两个进程：Checkout 对外处理下单和锁库存，OutboxDispatcher 在后台异步把订单事件投递出去  |
