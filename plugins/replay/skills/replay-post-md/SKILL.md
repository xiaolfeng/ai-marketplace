# Replay Post Markdown —— 对外发布的复盘报告

自己看的复盘回答「我刚才到底经历了什么」，对外的复盘回答「发生了什么、影响多大、为什么这样决策、之后怎么办」。本技能复用同一套逆向拆解结果，把它写成一篇**可以直接贴进 Wiki、周报、Issue 或技术博客的正式 Markdown 报告**。

口吻与脱敏按 [../_shared/audience-voice.md](../_shared/audience-voice.md) 的 Post 一节执行。

四个复盘技能的分工：

| 读者 \ 格式 | Markdown                       | HTML                                             |
| ----------- | ------------------------------ | ------------------------------------------------ |
| 自己看      | [replay-md](../replay-md/SKILL.md) | [replay-html](../replay-html/SKILL.md)       |
| 对外发布    | **replay-post-md（本技能）**   | [replay-post-html](../replay-post-html/SKILL.md) |

## 铁律

1. **先逆向收敛，再改写口吻。** 拆解与 `replay-md` 完全一致；落笔时改用团队视角，不写「你拍板」「我懵了」，不复述 AI 与用户之间的对话。
2. **结论先行。** 标题写「结果 + 关键转折」；摘要最多 3 条，每条都能单独转发。
3. **用数字说话。** 「影响」只放有真实数据的指标；不渲染情绪，去掉「猛猛」「铁证」「魔鬼细节」这类修辞。
4. **决策写出备选。** 每个关键决策列出当时的选项、采纳哪个、为什么没选其他。
5. **诚实标注未完成项。** 待执行、待审批、待外部发布的事项写进「后续事项」，不写成「已就绪」。
6. **发布前必须脱敏。** 逐条执行脱敏清单，文末写明处理了哪些类别的信息；作者署名由用户确认。

## 执行步骤

### 1. 拆解与确认读者

1. 按 [../_shared/reverse-methodology.md](../_shared/reverse-methodology.md) 盘点终局、逆向追因、折叠噪音，得到 5–9 个阶段；
2. 向用户确认**读者是谁**（团队内部其他组 / 管理者 / 公开社区）以及**署名与可公开范围**，读者越外部脱敏越严格。

### 2. 按骨架撰写

严格按 [references/post-structure.md](references/post-structure.md) 的顺序输出：元信息表 → 摘要 → 影响 → 背景 → 时间线 → 过程详述 → 关键决策 → 常见问题 → 现状与后续 → 经验与改进 → 脱敏说明。

### 3. 脱敏与自检

- [ ] 全文没有「你」「我懵了」等 Self 口吻，没有真实人名、内部域名、凭据与群聊原文？
- [ ] 摘要 3 条以内，没读过正文的人也能看懂？
- [ ] 影响里的每个数字都能在过程详述中找到出处？
- [ ] 每个决策都写了备选方案与理由？
- [ ] 后续事项都有负责方（角色）与触发条件？

## 特殊情况速查

| 信号                                         | 处置                                                                 | 条目 |
| -------------------------------------------- | -------------------------------------------------------------------- | ---- |
| 已经有一份 `replay-md` 自用稿                | 复用其中的步骤与证据，按 Post 口吻重写，删除对话细节，补齐 `publication` 字段 | P1   |
| 读者是管理者                                 | 摘要与影响放在最前，过程详述可只保留每阶段的结论段，证据收进 `<details>`    | P2   |
| 公开到社区或外部客户                         | 私有仓库只保留编号不放链接，业务数据改为比例或量级，署名改为团队名        | P3   |
| 用户还想要可分享的网页                       | 同一份数据交给 `replay-post-html`，产出翻页式正式报告                     | P4   |
