# HTML 交互式步进复盘页面规范（HTML Interaction & Design Spec）

本规范定义 `replay-html` 所产出的单文件 HTML 页面的视觉架构、交互状态机与响应式约束。

---

## 一、 核心设计哲学：像玩推理闯关游戏一样做复盘

当用户说「AI 一直在猛猛做，我很懵逼一直在点同意，给我理顺一条链路一步一步往下走」时，静态长页面最大的痛点是**视线容易往下滑脱、前因后果混在一起**。

因此，`replay-html` 采用 **「渐进式步进闯关 + 全景链路联动」** 架构：

1. **一次只看一关（Focus Mode）**：主舞台永远只渲染当前选中的 `Step k`，强迫视线按 `① 第一步看哪里` → `② 为什么要看这里` → `③ 发现了什么 & 做了什么` → `④ 认知破雾` → `⑤ 引申到哪里` 的顺序自然流动；
2. **随时知晓全局坐标（Context Awareness）**：顶部横向「因果节点轨道（Causal Stepper Bar）」与左侧「阶段关卡导航栏」实时高亮当前所在关卡、已通关关卡与待解锁关卡；
3. **点击「引申钩子」直接闯下一关（Causal Handoff Button）**：在每个 Step 底部第 5 要素「🔗 从这里引申到哪里」卡片中，直接提供一个醒目的大按钮 **「顺着这条线索进入 Step k+1：`<下一步看什么>` →」**，把「逻辑上的引申」变成「手指上的点击动作」；
4. **重型证据按需抽检（Evidence Drawer）**：右侧专栏展示本关对应的真实 Commit、代码片段、命令输出或审查原话，既不喧宾夺主，又能随时核验铁证。

## 二、 页面三视图与布局结构

+--------------------+-----------------------------------------+--------------------+

### 视图切换矩阵

| 视图 Tab                   | 适用场景                                                                                         |
| -------------------------- | ------------------------------------------------------------------------------------------------ |
| **🎮 步进闯关（默认）**    | 第一次复盘或头晕时使用：一步一步点「下一步」，顺着因果链走出来                                   |
| **🗺️ 全景链路 & 背景**     | 想纵览全局背景、四仓/多环境职责对照表，以及所有关卡首尾相连的完整因果瀑布流时使用                |
| **🧠 灵魂破雾 & 终局账单** | 想直接查看「为什么语音会关」「为什么去 staging-b」等高频疑问解答、已落袋成果和下一步待办表时使用 |

## 三、 交互与快捷键契约

1. **步进控制**：
   - 点击底部或顶部的 `← 上一步` / `下一步 →` 按钮；
   - 点击第 5 要素卡片内的 `顺着线索进入 Step k+1 →` 按钮（在最后一关时变为 `🎉 已通关全部链路 · 查看终局账单 →`，点击直接切到「灵魂破雾 & 终局账单」Tab）；
   - 键盘左/右方向键 `ArrowLeft` / `ArrowRight`（或 `j` / `k`）切换上一步/下一步；
   - 键盘数字键 `1`–`9` 直接跳转到对应关卡；
   - 切换关卡时主舞台平滑滚动回顶部，并触发轻微的卡片入场过渡动画。
2. **已读进度记录**：
   - 走过的关卡自动标记为 `visited`，顶部进度条实时显示已解锁比例。
3. **主题与导出**：
   - 支持 `Dark`（深邃极客蓝黑）与 `Light`（清爽纸张浅色）一键切换；
   - 支持「一键导出 Markdown 复盘稿」（由前端根据 `#replay-data` 实时拼装并下载 `.md` 文件！）与「打印 / 导出 PDF」（内置 `@media print` 样式，打印时自动展开全部关卡）。

## 四、 工程美学约束

- **外硬内柔**：遵循本仓库 `html` 插件家族规范，顶栏、面板外框与按钮采用干净利落的直角或微圆角（`2px-4px`），内部五要素卡片与标签采用柔和圆角与语义高亮色边条；
- **五要素语义配色**：
  - `📍 第一步看什么`：天际蓝（Sky Blue `#38bdf8`）—— 聚焦定位；
  - `💡 为什么要看这里`：琥珀金（Amber `#f59e0b`）—— 动机与警示；
  - `🛠️ 发现了什么 & 做了什么`：翡翠绿（Emerald `#10b981`）—— 落地行动；
  - `⚡ 认知破雾（误区 vs 真相）`：玫瑰红 vs 翠绿双栏对照（Rose `#f43f5e` / Emerald `#10b981`）；
  - `🔗 从这里引申到哪里`：电光紫（Violet `#8b5cf6`）—— 悬念与下一关传送门。
