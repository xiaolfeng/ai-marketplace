# 复盘组件库 (Replay Components)

本目录收纳步进复盘页的标准组件片段。样式全部由 [`../template.html`](../template.html) 提供，浅色 / 深色、响应式与打印都走同一套壳；片段只含最小可用 HTML 骨架与占位注释，**不要另写 `<style>`**。

页面默认由 `#replay-data` JSON 驱动渲染，这些片段既是脚本渲染产物的 DOM 骨架参考，也是在 JSON 表达不了的槽位（如 Pele 图表）手工扩展时的积木。带 `id` 的骨架片段（topbar / dock / drawer / term-pop 的气泡）是全页唯一壳件，一份页面只出现一次。

## 使用方式

复制 [`../template.html`](../template.html) 作为页面起点，只替换 `#replay-data` JSON 与 `<title>`；五要素、证据、词典等常规内容一律通过填 JSON 生成，不要手拼 HTML。只有 JSON 表达不了的内容（最典型是 Pele 图表）才把对应片段粘进对应 `render*` 函数的返回 HTML，并替换占位文案为事实。完整组合效果见 [`../../examples/example.html`](../../examples/example.html)。
