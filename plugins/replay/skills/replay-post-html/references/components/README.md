# 复盘报告组件库 (Post Report Components)

本目录收纳对外发布翻页复盘报告的标准组件片段。样式全部由 [`../template.html`](../template.html) 提供——**片段不带 `<style>`，模板是视觉唯一事实源**；浅色 / 深色、响应式与打印都走同一套壳。

## 使用方式

复制 [`../template.html`](../template.html) 作为报告起点：常规报告直接替换 `replay-data` JSON 即可，模板渲染器会按页面清单自动生成全部结构；需要扩写或定制区块时，才从本目录取片段填进对应槽位。片段给的是**结构与 `data-*` 契约**（`data-go` 翻页、`data-act` 菜单动作、`data-component` 组件标识），占位文案用真实事实替换。

片段是 HTML 片段而非完整文档（无 doctype / `<style>`），不要在生成页里另写样式——颜色、字体、圆角一律落回模板 token。图表用 Mermaid 语法写进 `pre.pele`，容器与加载约定见 [`pele-diagram.html`](./pele-diagram.html) 与 [`../post-html-spec.md`](../post-html-spec.md)。
