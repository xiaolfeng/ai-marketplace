## 一、攻击手法库

四类基础手法按需组合，每轮攻击主用一类，避免火力分散。选法速查：

| 用户主张的样子 | 优先手法 |
| --- | --- |
| 含「总是 / 都 / 不可能」等全称量词，或由少数几次经历归纳 | 反例构造 |
| 围绕阈值、规模、性能谈可行性 | 边界条件压测 |
| 只下了结论，机制层没讲清「为什么会这样」 | 机制追问 |
| 同一现象存在多种可能解释，用户只采信了一种 | 替代解释 |

### 1. 反例构造

- **适用**：主张以全称命题出现，或样本明显不足以支撑结论。
- **要领**：找一个真实存在的边界场景让主张失效；优先排查版本差异、极端规模、并发竞态、合规与审计要求。
- **话术示范**：「你说『分库分表总能解决容量问题』——跨分片的分布式事务和二级索引查询就是它的能力边界，某电商平台在做全局库存扣减时就翻车过，这里有一篇他们的复盘……」

### 2. 边界条件压测

- **适用**：用户用典型场景的表现推断全部场景。
- **要领**：沿「更大 / 更小 / 更冷门」三个方向推参数——流量十倍是什么样？数据冷到没人访问呢？依赖的服务挂了一个呢？每个方向问一层。
- **话术示范**：「平日 QPS 下这套限流没问题，那大促瞬间十倍脉冲进来，令牌桶恢复速度还跟得上吗？我们有做过这个量级的推演吗？」

### 3. 机制追问

- **适用**：用户能描述现象但讲不出成因链，或机制叙述有断层。
- **要领**：沿因果链逐环问「这一步为什么成立」，直到触达用户讲不下去的那一环——那一环就是盲区的入口。
- **话术示范**：「你提到『主从延迟导致读到了旧库存』，那从库是怎么同步的，半同步还是异步？延迟窗口通常多长，什么行为会把窗口拉大？」

### 4. 替代解释

- **适用**：用户把结果归因于单一嫌疑，但证据同样兼容其他解释。
- **要领**：并列提出 2~3 个同样说得通的候选成因，请用户逐一排除；排除不掉的那个往往会改写整个结论。
- **话术示范**：「超卖除了主从延迟，也可能是幂等校验缺失导致重试重复扣减，或者热点行更新串行化了。三个解释如何用当晚的日志区分开？」

## 二、弹药定级

辩论期所有证据按下表分级；终审官复核时沿用同一口径。

| 等级 | 标准 | 例 |
| --- | --- | --- |
| 强 | 官方文档明确陈述；可复现的一手实测数据 | 官方 Release Notes、自己环境里的压测报告 |
| 中 | 权威技术社区 / 大厂工程博客的二手经验，尚不可直接复现 | 收录于知名刊物的案例复盘 |
| 弱 | 无源可查、道听途说或超出核对能力的断言 | 「听说某公司这么用过」 |

使用规则：

1. AI 自己的开火默认携带 **强** 级弹药出处；拿不出就降调为「待核实假设」，不得当结论用；
2. 来源优先级：官方文档 > 权威技术资料 > 源码与基准实测；同级冲突时给出两边并列，不许静默取舍；
3. 只有 **弱** 级弹药可用的争点直接转平局悬置（对应 SKILL.md 速查表 E3），禁止装作确定。

## 三、战线判定

三种终态的判据如下，判定必须当场宣布并记入台账：

| 终态 | 判据 |
| --- | --- |
| 论点守住 | 用户在该战线给出了 AI 未能反驳的具体证据或实证经验，且论证逻辑闭合 |
| 盲区暴露 | 连续两轮接不住攻击（跑题、只有立场没有证据、答非所问），如实标记，禁止替用户圆场 |
| 平局悬置 | 双方各有逻辑但缺同一块硬证据；挂起时必须写明「需要什么证据才能裁决」 |

补充规则：

- 「用户嗓门大 / 态度坚决」不构成任何一种终态的依据；
- 盲区暴露不是失败惩罚，而是本次调研最有价值的产出之一——它精确标出了世界观缺口的位置；
- 悬置项不允许在辩论期内强行裁决，也不允许悄悄丢弃，一律进终审清单。

## 四、认输协议

动态立场的落地动作。当一条战线出现以下任一信号，AI 必须结算认输：

1. 用户拿出了 **强** 级证据，且覆盖了 AI 反例的核心场景；
2. 用户指出 AI 论证中的事实错误或逻辑断裂，经查证属实；
3. AI 找不到新的攻击角度，继续纠缠只会重复已驳倒的话。

认输格式固定，说清楚即可转场：

> 这条战线你赢了：<一句话理由>。计入台账，转入下一战线。

三条底线：

- 认输只针对当前战线，不外溢成对整个论题的投降；
- 明知站不住还换说法反扑，属于护短，直接违反 SKILL.md 铁律 2；
- 用户输掉的战线同样照实结算，不安慰、不放水——终审报告的真实性从这里开始积累。
