# INITDEEP.md 模板与标记规范

## 同步标记

每份由 `init-deep` 在 git 仓库生成或更新的 `INITDEEP.md` 首行写：

```html
<!-- init-deep:synced@<短哈希> -->
```

`<短哈希>` 是写入时的 `git rev-parse --short HEAD`；无 git 的全量生成不写标记。无标记的已有文件视为人工维护，先按 Q2 问询。标记之后空一行，再写标题。

## 扫描字段

| 字段 | 含义 |
| --- | --- |
| `git.isRepo / branch / head` | 仓库状态与当前提交短哈希 |
| `stats.totalFiles / truncated / languages` | 文件规模、截断情况和语言分布 |
| `tree[]` | 顶层目录及文件数 |
| `knowledgeBase[].path / scope / marked` | 已有 `INITDEEP.md` 所在位置、目录和标记 |
| `knowledgeBase[].diffSinceMarker` | 标记提交至 HEAD 对应目录的变动摘要；空字符串表示无变动，`null` 表示无法计算 |

## 子目录模板

```markdown
<!-- init-deep:synced@<短哈希> -->

# <目录名> · 知识索引

## 概述
一句话说明职责。

## 目录结构
用 text 代码块写直接子目录与关键文件；下层细节放下层索引。

## 导航指南
| 任务 | 位置 | 说明 |
| --- | --- | --- |
按任务指出实际入口。

## 约定
本目录独有、实际生效的规则及理由。

## 反模式
本目录易犯的错误及后果。

## 调试路径
可执行的排查顺序。

## 引用
- [子目录索引](./子目录/INITDEEP.md) — 适用情境
```

没有子级索引时省略「引用」。根索引沿用基础段落，并按需追加「代码地图」「模块架构（只写层级概览并链接架构文档）」「常用命令」；省略没有事实依据的段落。

## 格式

UTF-8、LF；路径与命令用行内代码，链接用相对路径。目录树只展示关键位置；基于真实代码校验符号与路径。语言跟随项目已有文档，未有明确主语言时使用中文。`AGENTS.md` 的简短入口遵循 [公共规范](../../_shared/agents-entry.md)。
