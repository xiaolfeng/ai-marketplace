# 工具适配与按需读取

`INITDEEP.md` 是目录知识索引，详情由任务触发后读取。根 `AGENTS.md` 是简短的自动加载入口，写法由 [公共规范](../../_shared/agents-entry.md) 决定。两者各司其职：文件路径和行为约束在一处维护，其他文件只保留链接与触发条件。

## 可选适配

用户明确需要跨工具接入时，先核对目标工具当前的加载机制，再按 Q4 询问要适配哪些客户端：

- 支持 `AGENTS.md` 的工具：使用根入口中的普通 Markdown 链接，具体资料由任务决定是否读取；
- 已有 `CLAUDE.md`：保留原有内容；如果用户要求它能看到新的入口，先展示仅引入短 `AGENTS.md` 的草案，由用户决定是否修改；
- 需要其他专属规则文件的工具：只放「何时读取 `INITDEEP.md` / `ARCHITECTURE.md`」的简短提示，核实该工具的路径解析方式后再写。

自动加载的文件只保留普遍适用的规则。完整目录树、架构全文和按模块变化的约束通过普通链接指路，避免把细节变成每轮固定上下文；尤其注意 `@` 形式的导入会立刻展开文件内容。
