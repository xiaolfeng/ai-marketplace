## 同步标记

每份由本技能生成或更新的 `AGENTS.md`，第一行必须是：

```html
<!-- deep-init:synced@<短哈希> -->
```

- `<短哈希>` 为写入时刻的 `git rev-parse --short HEAD`（7 位）；
- 标记是增量更新的唯一依据：无标记 = 人工维护文件，触发问询协议 Q2；
- 标记之后空一行再写正文标题；除标记行外正文不得包含其他 HTML 注释。

## scan.mjs 输出字段速查

| 字段 | 含义 |
| --- | --- |
| `git.isRepo / branch / head` | 仓库状态与当前 HEAD 短哈希 |
| `stats.totalFiles / truncated` | 文件总数与是否被上限截断 |
| `stats.languages` | 扩展名计数 Top 8，判断技术栈 |
| `tree[]` | 顶层条目及各自文件数，分层判定的输入 |
| `knowledgeBase[].marked` | 存量 AGENTS.md 是否带同步标记 |
| `knowledgeBase[].diffSinceMarker` | 自上次同步以来该目录的 `--shortstat` 摘要 |

`diffSinceMarker` 为空字符串 = 该目录自上次同步无变更；为 `null` = 哈希不在当前历史（见 edge-cases E3）。

## 子模块 AGENTS.md 模板（7 段）

```markdown
<!-- deep-init:synced@<短哈希> -->

# <目录名> 知识库

## 概述
一句话说明这个目录的职责和在项目中的角色。

## 目录结构
text 代码块展示目录树，只到直接子目录和关键文件；
子目录的内部结构由它自己的 AGENTS.md 负责，这里不展开。

## 导航指南
| 任务 | 位置 | 说明 |
| --- | --- | --- |
（常见任务 → 入口位置的映射，覆盖该模块最高频的 5~8 件事）

## 约定
本模块特有的编码约定和工作流规则。
每条先写「是什么」，紧跟「为什么」——只陈述不解释的约定 AI 记不住。

## 反模式
本模块中禁止或应避免的操作，每条附原因。

## 调试路径
问题出现在本模块时的典型排查顺序：
1. ... 2. ... 3. ...

## 引用
- [子目录名](./子目录/AGENTS.md) — 一句话说明
（没有子级 AGENTS.md 时整段省略）
```

## 根 AGENTS.md 模板（基础 + 扩展段）

根文件包含上述 7 段基础结构，另有按需启用的扩展段。**不需要的段落直接省略，不要留空标题**：

| 扩展段 | 启用条件 | 理由 |
| --- | --- | --- |
| 代码地图 | 有明显入口函数、核心类型或公共 API | 符号级索引是 AI 定位代码的最短路径 |
| 模块架构 | 存在 ≥2 个可独立描述的子系统 | 文字图/表格呈现层次关系 |
| 独特风格 | 有非标准的技术决策 | 防止 AI 按"标准做法"误改特殊实现 |
| 常用命令 | 有 Makefile / package.json 等构建配置 | 构建/测试/运行命令按用途分组放代码块 |
| 备注 | 有不适合其他段落的重要信息 | 已知限制、未完成事项、外部依赖特判 |

## 格式规范

- 编码 UTF-8，换行 LF；
- 目录树用 ` ```text ` 代码块；任务映射与符号索引用 Markdown 表格；
- 文件名、路径、命令一律行内代码包裹；
- 内容必须来自对代码的真实阅读，禁止编造符号或路径；
- 语言跟随项目既有文档语言；项目无既有文档时用中文。
