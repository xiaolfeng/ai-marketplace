## 问题
`dist/cursor/` 现在跟着仓库走，但没人说得清它算源码还是产物。
每次 `npm run build` 之后 git status 都有噪音，改错方向也没人发现过。

## 初步想法
- 干脆不入库，CI 里现生成——仓库最干净；
- 但消费方是直接读仓库的，不入库就断供了；
- 也许只有 cursor 清单该入库，dist 其余产物照旧忽略；
- 或者反过来全部入库，禁止本地重跑 build？

## 缺什么
- 各技能市场对「清单随仓库分发」的实际要求——是否允许 CI 生成；
- 本仓库 dist/ 目前实际被哪些工具引用（npx skills / ZCode）；
- 同类插件市场仓库怎么处理构建产物。
