5-WHYS ROOT CAUSE ANALYSIS / 根因连续追问 DRILL DOWN CHAIN
WHY 1 · 现象

为什么前端出现大面积 504 Gateway Timeout？

↳ 因为业务后端请求处理超时，连接全部被占满。
WHY 2 · 机制

为什么业务后端请求处理超时？

↳ 因为底层数据库在执行一条无索引的批量聚合查询引发全表锁。
WHY 3 · 流程

为什么生产环境会跑出无索引的批量聚合慢查询？

↳ 因为本次发布的新特性上线前未经过自动化 SQL 执行计划 Review。
WHY 4 · 规范

为什么没有经过自动化 SQL Review？

↳ 因为 CI 流水线中未配置自动慢 SQL 静态拦截门禁。
ROOT CAUSE · 根本原因

根本原因：发布体系缺少数据库 DDL/DML 的强制门禁检查，且熔断器超时阈值配置过长（30s）未起到快速失败保护。
