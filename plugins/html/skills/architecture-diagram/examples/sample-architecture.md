# 通用架构示例说明

[example.html](example.html) 只演示可替换的通用结构，不代表任何项目、第三方平台或部署环境或业务系统。

## 示例覆盖

- 不同尺寸的叶子节点、入口节点和主节点；
- 宽主节点中的两个职责分区；
- 同步、异步与安全通道的独立走廊；
- `connection-labels` 独立标签层，标签通过 `data-label-for` 关联线路；
- 每条线路用 `data-from` / `data-to` 关联节点，首尾端点吸附到卡片边界；
- 无背景框标签，全部占用自然留白；
- 一个低饱和虚线预留节点；
- 桌面与约 `390px` 移动视口响应式布局；
- 深浅主题、平移、缩放、重置与纯画布导出。

## 交付检查

- 节点与分区无物理重叠；
- 连线首尾端点对齐贴合节点边框；
- 标签占用自然呼吸留白；
- 纯 SVG 矢量导出与深浅主题切换正常。
