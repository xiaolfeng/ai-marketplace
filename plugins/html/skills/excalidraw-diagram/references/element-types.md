# Excalidraw 图元类型规范指南

本文件详细说明 Excalidraw 各图元类型的规范、几何属性、文字支持与典型适用场景。

## 图元类型速查

| 类型 | 视觉呈现 | 核心用途 | 内嵌文字支持 |
| --- | --- | --- | --- |
| `rectangle` | □ 矩形卡片 | 业务实体、服务组件、处理步骤、容器分层 | ✅ 支持（居中/多行） |
| `ellipse` | ○ 椭圆/圆形 | 起始/结束节点、生命周期状态、终端目标 | ✅ 支持（居中） |
| `diamond` | ◇ 菱形网关 | 分支决策、逻辑判断、合规判定、网关分流 | ✅ 支持（居中） |
| `arrow` | → 走向箭头 | 单向数据流、调用链路、时序依赖 | ❌ 需配合独立文本 |
| `line` | — 关系连线 | 无方向关联、分组分割线、辅助参考线 | ❌ 需配合独立文本 |
| `text` | A 手写文本 | 独立标题、注释说明、线路标签、步骤序号 | ✅ 本身即文本 |

---

## 1. 矩形 (Rectangle)

**最适合**：处理步骤、实体对象、微服务组件、持久层存储。

### 核心属性

```typescript
{
  type: "rectangle",
  roundness: { type: 3 },  // 3 代表手绘圆角，推荐用于所有业务实体
  text: "节点名称",         // 内嵌文本
  fontSize: 18,            // 推荐字号 16-20
  textAlign: "center",     // 水平居中
  verticalAlign: "middle"  // 垂直居中
}
```

### 推荐尺寸与色彩

| 场景 | 推荐尺寸 | 推荐背景色 | 描边粗细 |
| --- | --- | --- | --- |
| **客户端/接入层** | `150×80px` | `#a5d8ff` (浅蓝) | `2` |
| **核心业务微服务** | `160×85px` | `#b2f2bb` (浅绿) | `2` |
| **持久层与消息总线**| `160×80px` | `#d0bfff` (浅紫) | `2` |
| **告警/异常卡片** | `140×70px` | `#ffc9c9` (绯红) | `2` |
| **外层分组容器** | `400×240px`+ | `transparent` | `1` (虚线) |

---

## 2. 椭圆 (Ellipse)

**最适合**：流程起点、流程终点、状态机状态、强调圆环。

### 核心属性

```typescript
{
  type: "ellipse",
  text: "开始",
  fontSize: 18,
  textAlign: "center",
  verticalAlign: "middle",
  backgroundColor: "#b2f2bb"
}
```

### 推荐尺寸

- **起止圆角端点**：`110–130px` 宽，`55–65px` 高；
- **状态机正圆节点**：`80×80px` 或 `100×100px`。

---

## 3. 菱形 (Diamond)

**最适合**：判定决策、权限校验、风控打分、条件分支。

### 核心属性

```typescript
{
  type: "diamond",
  text: "校验通过?",
  fontSize: 15,
  textAlign: "center",
  verticalAlign: "middle",
  backgroundColor: "#ffd43b"  // 金黄高亮
}
```

### 尺寸规则

菱形由于几何对角收缩，有效内嵌文字面积小于同尺寸矩形：
- 简短判断（“通过?”、“合法?”）：`100×100px`；
- 复合判断（“风控打分是否通过?”）：`120×120px` 至 `140×140px`。宽高必须保持 `1:1`。

---

## 4. 连线与箭头 (Line & Arrow)

**最适合**：流转方向、服务调用、事件驱动、依赖关系。

### 核心属性

```typescript
{
  type: "arrow",
  points: [[0, 0], [deltaX, deltaY]],  // 相对起点的相对偏移量
  roundness: { type: 2 },              // 2 代表自然微弯手绘线
  strokeStyle: "solid",                // solid | dashed | dotted
  strokeWidth: 2
}
```

### 走线方向与线型语义

- **水平正交调用**：`points: [[0, 0], [100, 0]]`，用于主业务推进；
- **垂直正交流转**：`points: [[0, 0], [0, 90]]`，用于层级穿透或降级流；
- **米字转折走线**：`points: [[0, 0], [midX, 0], [midX, deltaY]]`，曼哈顿正交折弯；
- **线型规范**：
  - `solid`：同步 HTTP / RPC 主调用链路；
  - `dashed`：异步 MQ 消息投递、事件解耦流或异常拦截回滚；
  - `dotted`：可选路径、弱依赖或只读查询走廊。

### 箭头文本标签配合

箭头不直接内置文字，必须在箭头中点旁放置独立 `text` 元素：

```json
[
  {
    "type": "arrow",
    "x": 200,
    "y": 150,
    "points": [[0, 0], [120, 0]]
  },
  {
    "type": "text",
    "x": 235,
    "y": 130,
    "text": "HTTPS 提单",
    "fontSize": 13,
    "strokeColor": "#64748b"
  }
]
```

---

## 5. 独立文本 (Text)

**最适合**：页面标题、大纲段落、连线说明、角标说明。

### 核心属性

```typescript
{
  type: "text",
  text: "系统主标题",
  fontSize: 28,
  fontFamily: 5,       // 强制统一使用手写风格字体
  textAlign: "center",
  verticalAlign: "top"
}
```

### 字号层级标准

| 层级 | 推荐字号 | 适用场景 |
| --- | --- | --- |
| **主标题 (H1)** | `28–34px` | 画布主标题 |
| **子分区标题 (H2)** | `20–24px` | 泳道分组头、子网络集群名称 |
| **图元正文** | `15–18px` | 核心服务名、步骤名称 |
| **连线与参数说明** | `12–14px` | 协议标注、判定分支是/否、返回状态码 |
