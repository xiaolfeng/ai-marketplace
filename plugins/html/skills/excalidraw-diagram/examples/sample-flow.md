# 电商订单结算与风控履约示例说明

[example.html](example.html) 演示了使用 `excalidraw-diagram` 生成的端到端手绘白板业务流程与架构拓扑。

## 示例覆盖

- **核心实体与步骤**：包含用户端下单、API 接入网关、核心订单服务、支付清算服务、库存中心与仓储履约系统的全链路卡片；
- **条件判定与决策分支**：菱形网关展示风控合规判定与支付成功判定，支持成功流、拦截流与失败回退分支；
- **存储与事件总线**：展示带有手绘排线（`hachure` 与 `cross-hatch`）的 MySQL 订单库、Redis 缓存与 Kafka 消息队列；
- **连线与端点吸附**：包含实线同步调用、虚线异步事件驱动、双向流转与直角米字折线；
- **全格式导出能力**：支持导出纯矢量 SVG、2x 视网膜 PNG、高保真 PDF，并可一键下载原生 `.excalidraw` 源码文件或一键跳转官网编辑；
- **自适应视口**：集成自适应视口平移拖拽、滚轮缩放、双主题切换以及约 `390px` 移动端响应式布局。
