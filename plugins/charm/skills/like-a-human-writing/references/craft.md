## 一、burstiness 注入

**依据**：人机文本最稳定的结构指纹是句长方差——AI 稳定压在 12–17 词窄幅，
人类分布在 15–25 且忽长忽短（文献 W2、W3）。

操作：

1. 长句讲完一轮论证，**用一个短句收拳**。「整条链路上的缓存、限流和重试都需要同步改造，其中缓存又牵扯本地与远端两级。——这是本次最大的坑。」
2. 允许**单句成段**。一句话够重就让它独占一段，留白本身是节奏。
3. 用破折号插入语打断匀速感：「这个方案——至少在现在这个规模下——还撑得住。」
4. 检查标准：随机抽相邻五句，长度差应肉眼可见；仍然整齐就再砍一句。

## 二、具体性革命

**依据**：Orwell 序言——措辞含混的根源是想偷懒，先让画面与感觉在脑中清晰，
词会自己跟上来（W7）。

操作：

1. 抽象名词换成能拍照的东西：「提升用户体验」→「用户少点两次、少等三秒」。
2. 形容词必须带量才准入：「显著提升」要么给出数字，要么换掉「显著」。
3. 术语第一次出现就给一句人话解释，哪怕读者可能是同行——解释本身暴露作者真的懂。
4. 数字保留原样：活人写东西爱引用具体版本号、日期、故障时长，机器爱写「大幅」「多次」。

## 三、立场回归

**依据**：AI 文本几乎不出现 booster 型立场词（显然 / 说实话 / 遗憾的是），
全文像匿名审稿意见（W3）；而立场与反思恰是人味核心。

操作：

1. 每三百字至少一次可见的态度标记：「我认为」「老实讲」「麻烦的是」「可惜」。
2. 有偏好就摆出来：「两个方案里我更喜欢 A，理由很俗：省心。」和稀泥才是机器味。
3. 承认局限要具体：「这块我没在生产验证过」好过「可能存在一定局限性」。

## 四、词语降级

**依据**：Orwell 规则二与 Zinsser 的 clutter 清除——能用短词不用长词，
「utilize → use」（W8）；AI 文本的词典雅密度恰与可读性负相关（W1）。

中文对照速查（保留原意的动词优先原则）：

| AI 腔 | 人话 |
| --- | --- |
| 进行 X 操作 | 做 X |
| 利用该工具 | 用它 |
| 实现了对 X 的支持 | 支持 X |
| 助力 / 赋能 | 帮 |
| 存在一定的不足 | 还不够好 |
| 相关工作人员 | 谁，说名字 |

## 五、开头结尾去套路

- 开头禁用自问自答与背景铺垫超过两句；第一段必须出现正题的具体对象；
- 结尾禁用总结复述；给一个向前看的动作、一个没答完的问题，或者干脆停在最有劲的那句；
- 过渡靠逻辑自然衔接，不靠「接下来我们来看」「综上所述」这类路标牌。

## 六、终检三问

1. **朗读测试**（Zinsser）：默读一遍，哪里绊嘴改哪里；
2. **删减测试**：任意抽删一句话，意思没丢就真删；
3. **署名测试**：这篇东西挂上你的名字发出去，会不会脸红？会脸红的句子就是还有病灶。
