# Like a Human Writing —— 魅力文学·写作系

让书面文本长出一张活人的脸。方法论不是审美偏好，站在两块地基上：
**人机文本的实证差异**（人类文字的句长方差大、立场词丰富、可读性优先；
AI 文字句长均一、立场缺席、华丽但难读）与**经典写作准则**
（Orwell 的画面优先六则、Zinsser 的砍冗余纪律）。
完整文献见 [../_shared/human-sources.md](../_shared/human-sources.md)。

与 [like-a-human-speaking](../like-a-human-speaking/SKILL.md) 的分工：
本技能管**成文的段落**——文章、博客、README、长回复；聊天消息、群公告、
客服话术等回合制对话文本交给 speaking 系。

## 铁律

1. **先诊断后动笔。** 对照 [../_shared/slop-blacklist.md](../_shared/slop-blacklist.md) 逐条打标签，确定病灶分布再下刀；禁止凭感觉无差别乱改。
2. **学成熟作者的人味，不复制新手的病句。** 研究显示人类文本错别字更多——但那是「初稿的人」，不是「好作者的人」；要移植的是节奏、立场与具体性，不是拼写错误。
3. **保真高于漂亮。** 不改事实、数字、术语与用户原意；原意有歧义时是唯一允许停下来询问的情形。
4. **文体分级介入。** 三档标准见执行步骤 §1；用户未指定档位时按内容性质判定，并在交付时说明采用了哪一档。
5. **手法有出处。** 每类改法对应手法库编号；引用研究结论时区分「研究原文说了什么」与「我们的移植推断」，禁止拿实证给自己的偏好站台。

## 执行步骤

### 1. 判级

| 档位 | 适用文体 | 动作幅度 |
| --- | --- | --- |
| 克制档 | 技术规范、API 文案、错误信息、法务口径 | 只清黑名单病灶，不加人味修饰 |
| 标准档 | README、邮件、产品介绍、常规博客 | 去病灶 + 轻度节奏调整 |
| 放开档 | 随笔、社评、叙事文、观点长文 | 全套手法可用，鼓励可见的作者在场 |

### 2. 诊断

通读全文，对照黑名单记录病灶编号与位置（如「B4·第 2 段」「B5·全文」）。
全文干净就直说不需要改，不为了显得干了活而硬造问题。

### 3. 重写

按病灶选手法，细则与例句对照见 [references/craft.md](references/craft.md)：

- B4 句长均一 → §一 burstiness 注入
- B6/A5 华丽降智、名词化 → §四 词语降级
- B5 立场缺席 → §三 立场回归
- B1/B3 结构套路 → §五 开头结尾去套路 + 文气重组

### 4. 出稿

三段式交付：**原文标注**（病灶定位）→ **改后全文** → **改动说明**
（哪几处对应哪些黑名单条目与手法）。克制档交付时省略说明中的人味话术。

## 特殊情况速查

| 信号 | 处置 | 条目 |
| --- | --- | --- |
| 用户附了自己的文字样本让照着写 | 样本文风为最高基准，通用法则退居查漏 | E1 |
| 改了两轮越改越僵 | 回滚到上一稿重选档位，向用户摊牌档位问题 | E2 |
| 全文无病灶 | 如实告知，仅指出一两处可选优化 | E3 |
| 用户要求「再专业一点」（反向诉求） | 属加 Formality 方向，不在本技能目标内，走常规润色并说明 | E4 |
| 原意歧义影响改写方向 | 按 Q 唯一问询情形给候选理解各附改法草案 | Q |

## 自检

- [ ] 诊断在动笔前完成且留了标签记录
- [ ] 没有把病句当人味移植进来
- [ ] 事实、数字、术语与用户原意零篡改
- [ ] 档位经过判定并在交付时说明（或用户指定）
- [ ] 改动说明里的每处修改都能对回黑名单或手法库编号
- [ ] 引用的研究结论没有超出原文支持范围
