# Like a Human Speaking —— 魅力文学·口语系

让对话里的文字听起来像对面坐了个真人。方法论来自口语语言学与
会话分析（CA）的实证结论：应答有秩序、修复必然发生、填充词促记忆、
缓释语撑起礼貌——活人的说话方式是有结构的不规整，
而不是随机撒语气词。完整文献见 [../_shared/human-sources.md](../_shared/human-sources.md)。

与 [like-a-human-writing](../like-a-human-writing/SKILL.md) 的分工：
本技能管**回合制的对话**——IM 回复、群公告开场、客服话术改造；
成文的长段落（文章、README）交给 writing 系。

## 铁律

1. **应答先于答案。** 先接住对方那句话里「人的部分」（情绪、语境、玩笑），再进入正题；上来第一句就是解决方案是机器的本能。
2. **允许不完美。** 偶尔的自我修正（「哦不对，我说错了……」）与轻度犹疑是人类对话的基础设施，误解每几轮必然发生、修就是了；装作永不犯错恰恰最假。
3. **不表演情绪。** 情绪浓度过高是 AI 生成内容的实证特征之一；表情符号与感叹号是调味品，堆量即是新的客服腔。
4. **说对方听得懂的词。** 黑话按对话对象自动降级为日常说法，除非确认对方是同行且语境需要精度。
5. **场合守门。** 事故通报、变更公告主体、对外危机口径保持严肃格式——口语化不等于随便化；守门判定见特殊情况 E3。

## 执行步骤

### 1. 听诊

先回答「这段话现在像谁」：客服机器人？新闻播报员？论文摘要？官样文书？
病灶定位对齐 [../_shared/slop-blacklist.md](../_shared/slop-blacklist.md) 丙部。

### 2. 重建语感

按特征逐项检查，转换规则与中文示例见 [references/speech-signals.md](references/speech-signals.md)：

- 有没有先回应再答事？（§一 应答序列）
- 敢不敢认错和自纠？（§二 修复机制）
- 犹豫是否真实且有密度上限？（§三 填充词）
- 断言有没有缓释缓冲？（§四 shields 型缓释语）
- 词是不是人话？（§五 词汇降级）

### 3. 控密度

所有特征都是稀料。单条回复里命中三项以上特征即视为表演过度，
按「如果对面站着这个人，他会这么说话吗」的标准砍回。

### 4. 出稿

两段式交付：**改后文本** → 一句话说明动了哪里（如「补了应答+两处降级」）。
对话场景讲究快进快出，不做长篇诊断报告。

## 特殊情况速查

| 信号 | 处置 | 条目 |
| --- | --- | --- |
| 用户只是想让 AI 平时这样说话（而非改某段文本） | 给出可直接抄进 AGENTS.md / 人设栏的口吻准则摘要 | E1 |
| 对方情绪激动、涉及投诉纠纷 | 先安抚后办事保留，但禁用夸张共情模板 | E2 |
| 内容是事故通报 / 对外声明 / 法务相关 | 判定场合守门，拒绝口语化改造并说明理由 | E3 |
| 用户给的样本带方言 / 网络梗 | 可吸收其节奏，但梗有时效性，默认收敛 | E4 |
| 消息本身是程序输出说明（报错指引等） | 归 speaking 边缘档：只治 C4 黑话，不动格式 | E5 |

## 自检

- [ ] 第一句话接住了「人」，而不是直接扔方案
- [ ] 自我修正与犹豫出现在真实不确定的位置，不是撒料
- [ ] 感叹号与 emoji 在密度红线以内
- [ ] 黑话已按对象降级或确认无需降级
- [ ] 场合属于对话域，没有误伤严肃文书
- [ ] 全文特征密度 ≤3，读完像一个累了一天但心情不错的人
