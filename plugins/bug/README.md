# bug

面向 AI 编码助手的缺陷工作流：把「找质量问题」「做安全审查」「按根因修」拆成三个互斥技能，避免边找边改、把空指针报成漏洞、或没复现就出补丁。

| 技能 | 触发词示例 | 说明 |
| --- | --- | --- |
| `find-bug` | 「找 bug」「review 这段正确性」 | 质量缺陷发现：正确性 / 并发 / 资源 / 契约，只出清单不修 |
| `find-security-bug` | 「安全审查」「有没有越权/注入」 | 授权范围内的安全审查：OWASP Top 10:2025 + CWE，只取证不写利用 |
| `fix-bug` | 「修这个 bug」「按 Q-01 改」 | 复现 → 根因 → 最小修复 → 回归；禁止症状式补丁 |

## 设计要点

- **发现与修复分家**：find-* 不改业务代码；同一句话里「找完就修」也是先交清单再切换；
- **质量与安全分家**：空指针、竞态、泄漏默认走 `find-bug`；越权、注入、密钥走 `find-security-bug`；
- **证据分级**：失败测试 / 完整数据流 / 局部反模式 对应 确定 / 倾向 / 存疑，没有新证据不许靠措辞升级；
- **安全取证边界**：默认只读本仓库指定路径，不写 payload 与 exploit，密钥只报位置不抄值。

每个技能附 `references/`（分类或手法）、`examples/`（完整示范）与 `evals/`（触发评测集）；三份技能共用的清单模板在 [`skills/_shared/`](skills/_shared/)。

## 安装

```bash
npx plugins add xiaolfeng/ai-marketplace@bug
```
